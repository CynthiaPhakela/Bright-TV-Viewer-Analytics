# Bright-TV-Viewer-Analytics
This project analyzes Bright TV viewing data using Databricks SQL and Dashboards to uncover audience behavior, content performance, and business growth opportunities.
Tools used - Miro: Miro for project planning and Canva for Brainstorming. Databricks SQL to analyse the data. Dashboards for storytelling done via: Databricks, Excel Pivot Tables, Data Studio and an interactive Dashboard via Lovable.
